# Sunbreak ☀️

A personal sunshine opportunity planner for San Francisco.

Sunbreak helps users discover upcoming sunny days, explore historical weather patterns, and make time to enjoy the outdoors.

## Tech Stack

- React
- Python / FastAPI
- PostgreSQL (planned)
- Open-Meteo API
- Recharts (planned)
